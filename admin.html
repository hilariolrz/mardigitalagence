Activer l'upload d'images et de fichiers

Pour pouvoir uploader des images (photos, formations) et des fichiers (PDF, vidéos) depuis l'admin, il faut créer deux dossiers de stockage dans ton projet Supabase. C'est gratuit et ça prend 2 minutes :

  1. Va sur supabase.com → ton projet → menu de gauche Storage
  2. Clique New bucket → nom : portfolio-images → coche Public → Create
  3. Refais pareil → nom : formations-files → coche Public → Create

C'est tout. Les uploads fonctionneront automatiquement après ça.

Comment donner accès à une formation

Voici le processus actuel (manuel) pour accorder l'accès à un acheteur :

1
Client achète

Le client clique "Acheter", remplit son nom/email/WhatsApp dans la modale.

2
Tu confirmes le paiement

Tu reçois l'info (WhatsApp/email). Tu vas dans Fichiers formations et tu copies le lien du fichier.

3
Tu envoies le lien

Tu envoies le lien Supabase Storage au client par WhatsApp ou email. Il télécharge directement.

Prochaine étape : Intégrer Stripe pour automatiser tout ça — paiement confirmé = lien envoyé automatiquement par email.

EmailJS — Envoi email au client

EmailJS permet d'envoyer l'email d'accès directement au client depuis ton navigateur. Gratuit jusqu'à 200 emails/mois. emailjs.com →

Configuration en 3 étapes :
1. Crée un compte sur emailjs.com → Add New Service → choisis Gmail → connecte ton email
2. Va dans Email Templates → Create Template → note le Template ID
3. Va dans Account → API Keys → copie ta Public Key
